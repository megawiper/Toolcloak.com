# Features

> Everything you can do on toolcloak.com.

Everything you can do on [toolcloak.com](https://toolcloak.com).

## Every tool page
Each tool has its own page with **Free**, **Private** and **Instant** tags and the same layout:

| Element | Purpose |
|---|---|
| Upload or input area | Click, drag and drop, or paste (Ctrl+V works anywhere on the page) |
| **Try with a sample file** | See the tool work without using your own file |
| **Wishlist** star | Pin the tool for quick access |
| **Chain** button | Add the tool to a chain, or start a new chain with it |
| **Explain with Fedra** | Ask the assistant to explain the tool |
| **Full guide** card | The long-form article behind the tool |
| Result card | **Download**, **Send to** another tool, **Save to Artifacts** |
| **Share link** | Inputs packed into the URL fragment (`#s=...`), never sent to a server |
| History panel | Your inputs, results and result files, on this device |
| **Embed this tool** | Copy-paste code for your own website |
| Donate button | Appears after a result for tools that need an action, at once for tools that answer by themselves |
| Sponsor slot | A clearly labelled placement |
| Similar tools, related guides | Six similar tools and four guide tiles |

## Find things fast
- **One search for everything.** Tools, your chains, saved files, History, pages, settings (try "dark mode") and article sections, grouped. `/` or `Ctrl+K` focuses the search box.
- **Top bar** with Chains, History and Menu. The menu has search first, quick tiles (Chains, History, Saved files, Wishlist), the Light / Dark / Auto switch and every category.
- **Trail bar.** A breadcrumb that follows how you actually got here, with a back arrow. Swipe between the five main pages on a phone.

## Build things
- [Studios](STUDIOS.md) for PDFs, scanning, documents, spreadsheets, design, data, graphs and 3D.
- [Tool Chains](TOOL_CHAINS.md) to link tools into one flow.
- **Drop Zone** (`/drop`, and the big box on the home page): drop any file and get suggestions.
- **Send to.** Any text result or image, PDF, audio or video download can be passed to another tool.

## Get help
- [Fedra](FEDRA.md), the on-device assistant.
- [Voice and automation](VOICE_AND_AUTOMATION.md).
- A guide behind every tool: [GUIDES](GUIDES.md).

## Keep your work
- **Artifacts:** every result is saved automatically in IndexedDB, once, at its own size. Your uploaded file is never stored.
- **History:** inputs, results and result files, with your permission, on this device.
- **My Space and Sync:** [MY_SPACE_AND_SYNC](MY_SPACE_AND_SYNC.md).
- **Backup:** export and import history, saved results and wishlist as JSON, or everything as a ZIP. Import merges and overwrites nothing.

## Make it yours
- **Light, Dark or Auto** theme.
- **Region and currency** (rupee amounts can be shown in your currency), and a translate option. See [REGION_AND_TRANSLATE](REGION_AND_TRANSLATE.md).
- **Settings:** voice and automation, storage and space, check for updates, clear or export your data.

## Install and go offline
Installable as an app, with offline pages and cached libraries. See [PWA_AND_OFFLINE](PWA_AND_OFFLINE.md).

## Share and support
- **Share box** with a QR code, WhatsApp, Telegram, X, Facebook, Email and Copy. Links opened show a small "Made with Toolcloak" banner.
- **Donate** by UPI, **Supporters** wall, **Sponsor** placements, **Templates** shop (coming soon), **Custom tool** requests. See [ADVERTISE](ADVERTISE.md).
- **Embed** any tool: [EMBED](EMBED.md).
