# FAQ

**Is Toolcloak free?** Yes, every tool page is tagged Free. There is no sign-up.

**Do my files get uploaded?** No. Tools run in your browser and the site is static, so there is no server of ours to receive them. A live pill shows "0 bytes uploaded". Tools that must reach an address you type (API Request Builder, CORS Tester, DNS Lookup) are the exception by nature. See [PRIVACY](PRIVACY.md).

**How can I check?** Open `/privacy-proof`, watch your browser's Network tab, or turn off your connection and use a tool you have already opened.

**Do you track me?** The site counts visits with Google Analytics 4 with advertising features off. In the EU it only starts after you press Accept. No analytics event carries what you typed.

**Why does History say "off"?** You declined cookies, or have not decided yet. Allow it and your inputs, results and files are saved **on this device only**.

**Why does PDF to Word give me no text?** Your PDF is probably a scan, which is just pictures. Run **Image to Text (OCR)** first. OCR supports 13 languages.

**What is Fedra?** The on-device assistant. It plans multi-step jobs and answers how-to questions from the site's own guides. No AI model, no server.

**What are Studios?** Workspaces for PDFs, scanning, documents, spreadsheets, design, data, graphs and 3D. They save to My Space on your device. See [STUDIOS](STUDIOS.md).

**What is a chain?** Tools linked into one flow, run in one tap. See [TOOL_CHAINS](TOOL_CHAINS.md).

**Can I use it offline?** Yes. Install it as an app. Pages you have opened keep working. See [PWA_AND_OFFLINE](PWA_AND_OFFLINE.md).

**Can I move my work to another device?** Yes. `/sync` links two of your devices directly with a QR code. No account.

**Is the black cover in PDF Studio real redaction?** No. It only hides what you see. Use *Shrink hard* to remove content.

**Is the signature legally binding?** No. It is a picture.

**Can I put a tool on my website?** Yes. See [EMBED](EMBED.md).

**Can I advertise or sponsor?** Yes. See [ADVERTISE](ADVERTISE.md).

**Can I request a tool?** Yes. Use the custom tool page or open a feature request.

**I found a bug.** Open an issue with the bug template. Security problems: [../SECURITY.md](../SECURITY.md).
