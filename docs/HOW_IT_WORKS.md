# How a tool page works

> A walk through one tool page, step by step.

Using **PDF to Word** as the example.

1. **Header and tabs.** Menu, microphone, search and theme switch on top. Tabs for Home, All tools, Studios, Guides and Library below.
2. **Breadcrumb.** Tools, then the tool name.
3. **Tool card.** Name, category tag (PDF Tools), a one-line description and the **Free / Private / Instant** tags. **Wishlist** and **Chain** buttons sit on the right.
4. **Upload area.** Click or drag and drop. Only supported file types are accepted. **Try with a sample file** lets you test first.
5. **Explain with Fedra.** Opens the assistant to explain the tool.
6. **Guide card.** A link to the full article behind the tool.
7. **Embed this tool on your website.** Free. See [EMBED](EMBED.md).
8. **Sponsored slot.** A clearly marked ad placement. See [ADVERTISE](ADVERTISE.md).
9. **Similar tools.** Six related tools as quick links.
10. **History.** Saved inputs and results, on your device, if you allow it. See [PRIVACY](PRIVACY.md).
11. **At a glance.** A mini picture of input and output.
12. **Step by step.** Numbered steps: choose the file, run the tool, copy or edit, save.
13. **The upload pill.** When you pick a file or a result appears, a small pill says how many bytes of files this page has uploaded. It should say 0.

> **Good to know:** PDF to Word extracts the text of a PDF. It works best on PDFs made from Word or Docs (real text). Scanned pages that are just pictures have no text to extract. Use the OCR tool for those.
