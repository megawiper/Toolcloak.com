# Support

1. **Check the FAQ:** [FAQ.md](FAQ.md).
2. **Read the guide** linked from the tool page. It often answers the question.
3. **Ask Fedra** with the *Explain with Fedra* button.
4. **Open an issue** with the bug or question template.
5. **Security problem?** Do not open a public issue. See [../SECURITY.md](../SECURITY.md).

When reporting a bug, include the tool name, your browser and device, and what you expected to happen.
