# Support

> Stuck? Work down this list. Most questions end at step 1 or 2.

| | Step |
|:---:|---|
| 1️⃣ | **Check the FAQ:** [FAQ.md](FAQ.md) |
| 2️⃣ | **Read the guide** linked from the tool page. It often answers the question. |
| 3️⃣ | **Ask Fedra** with the *Explain with Fedra* button. |
| 4️⃣ | **Open an issue** with the [bug](https://github.com/megawiper/toolcloak.com/issues/new?template=bug_report.md) or [idea](https://github.com/megawiper/toolcloak.com/issues/new?template=feature_request.md) template. |
| 5️⃣ | **Security problem?** Do not open a public issue. See [../SECURITY.md](../SECURITY.md). |

When reporting a bug, include the tool name, your browser and device, and what you expected to happen.
