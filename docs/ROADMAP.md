# Roadmap

> A living list built from the project's own "not built yet" notes. Items move as priorities change.

## 🔥 Now

- [ ] Thorough SEO pass, and the Toolcloak name and favicon in Google results
- [ ] More guides built around high-volume search questions
- [ ] Merge or differentiate overlapping guides (the two colour-format ones)
- [ ] Commit `package-lock.json` (run the *Make package-lock* workflow) and add Dependabot
- [ ] Renew `security.txt` before it expires

## ⏭️ Next

- [ ] Tighten the Content-Security-Policy (nonces or hashes instead of `'unsafe-inline'` and `'unsafe-eval'`)
- [ ] Close Fedra's option gaps (see `ASSISTANT-REPORT.md`) so more tools run with named options
- [ ] Send a chain into a Studio
- [ ] PDF Studio: real redaction, freehand pen, comments panel
- [ ] Per-tool preview images for social sharing

## 🔭 Later

- [ ] **Fedra smart mode:** opt-in in-browser model that only turns messy English into the same plan format
- [ ] Scanner auto-corner detection
- [ ] Edit existing PDF text in place
- [ ] Sheets: pivot tables
- [ ] New studios: slides, whiteboard, mind map, kanban
- [ ] Design Studio: two-finger rotate
- [ ] GLB support in the 3D viewer
- [ ] More languages for Fedra and the interface

## 💬 Ideas welcome

[Open a feature request](https://github.com/megawiper/toolcloak.com/issues/new?template=feature_request.md) and tell us what you were trying to do.
