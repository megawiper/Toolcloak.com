# Changelog

> All notable changes are listed here, newest first.
> Earlier history lives in [docs/DEVELOPMENT_LOG.md](docs/DEVELOPMENT_LOG.md) (version-by-version notes and design decisions) and [docs/PDF_STUDIO_CHANGELOG.md](docs/PDF_STUDIO_CHANGELOG.md).

## [Unreleased]

### ✨ Added
- A redesigned README: new animated banner, a feature-card strip, a nine-second desktop demo, a category table, GitHub callouts and a clear quick start
- `docs/README.md`, a documentation index with one card per page
- A new **desktop demo** (`assets/media/demo-desktop.gif` and `.mp4`, 1920x1080, nine seconds): the file picker is cut out, with step captions and the "0 bytes uploaded" pill
- `assets/highlights.svg`, an animated "Why it is different" strip
- A header with breadcrumbs and a footer with a link back to the README on every Markdown file
- Documentation set: features, tools, studios, tool chains, Fedra, My Space and sync, voice, embed, PWA, region, guides, privacy, security practices, SEO, architecture, tech stack, project structure, deployment, scripts, testing, ADDING_A_TOOL, ADDING_AN_ARTICLE, roadmap, FAQ, branding, advertise and support
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, issue and pull request templates
- Brand assets: wordmark, icon and favicon sizes, cropped screenshots, phone-frame showcase

### 🔧 Changed
- The repository is now referred to as **`megawiper/toolcloak.com`** everywhere (clone commands, badges, terminal animation, templates)
- The demo now appears once, at the top of the README, instead of twice
- The animated banner and the terminal SVG were rebuilt
- The previous development-log README moved to `docs/DEVELOPMENT_LOG.md`

### 🗑️ Removed
- The old phone-shaped clips `demo-short` and `demo-full` (GIF and MP4)
